## 🛠️ How to Use NetraUploader

Using NetraUploader is a breeze. Here's a step-by-step guide:

### 1. Set Up Your Telegram Bot

Before you can upload files, you need a Telegram bot. Don't worry—it's easier than it sounds:

- Open Telegram and search for **@BotFather**.
- Start a chat with BotFather and send the command `/newbot`.
- Follow the prompts to name your bot. You'll receive a **token** (a long string of numbers and letters) when you're done.
- Keep this token safe—you'll need it for NetraUploader.

### 2. Get Your Chat ID

You also need to know where to send your files. Your **Chat ID** is a number that identifies your Telegram account or channel:

- If you're using your own chat, search for **@userinfobot** on Telegram and start a chat. It will show you your Chat ID.
- For a channel, add the bot to your channel as an admin, then send a message to the channel. You can find the Chat ID using Telegram's web version or by using the bot.

### 3. Enter Your Details in NetraUploader

When you open NetraUploader, you'll see a simple interface. Enter:

- **Bot Token** – The token you got from BotFather.
- **Chat ID** – The ID where your files should be sent.
- **Select File** – Choose the file you want to upload.

Then click **Upload** or **Send**. That's all there is to it!

## 🧰 Troubleshooting Common Issues

### The upload fails or gets stuck
- Check your internet connection.
- Ensure your bot token and Chat ID are correct (no extra spaces).
- Try a smaller file to test if the issue is file size.

### The app doesn't start
- Make sure you've run the latest version from the download page.
- Temporarily disable antivirus software if it blocks the app.
- Restart your computer and try again.

### Files arrive but are corrupted
- Check the file size before and after upload.
- Use a stable internet connection.
- Re-download the file if it's corrupted on your end.
